# 系统与应用

更新于 2026-09-10 · 概念关系

TALOS 是整体系统与品牌。Agent OS 表达组织人与智能体工作的架构理念，各应用和场景按自身职责逐步接入。下表解释用途，不代表全部连接已经完成。

| 部分 | 职责 | 当前关系与边界 |
|---|---|---|
| TALOS 资料库 | 整理、来源检索、偏好采用与资料维护 | 面向日常资料使用的实现候选，真实用户体验仍待验证 |
| TALOS Lens | 资料和项目的图形总览、版本与数据问题、升级参考 | 本机统计应用；只读观察，不执行 AO 任务或修改原项目状态 |
| AO / AOR | 任务分工、执行、独立审查、进度与恢复 | 编码执行组件候选；主智能体委派的新模式仍需真实模型完整验证 |
| lili | 统一桌面工作台、项目与应用入口 | 沿用已有桌面能力与各自接入合同；不同版本验证分别记录 |
| TALOS Plugin | Obsidian 中的资料、对话及工作入口 | 插件各版本有自己的功能与兼容范围，不代表完整 TALOS 全部交付 |
| DHC | 从手机控制在线 Mac 上的工作 | 手机远程入口探索；依赖实际设备和运行环境 |
| Agent Cockpit | 本机设备输入与免键鼠操作 | 活跃比较候选，真实控制能力按验证范围说明 |
| 屈原 | 快捷唤起的语音交互与只读查询 | 独立语音入口候选，完整使用体验仍需验收 |
| 论文研究、Blender 工作流 | 专业研究和创作场景 | 用于验证共同方法在具体任务中的适用性 |
| 学习与指导 | 帮助用户配置并使用工作系统 | 教程、示例与实践方法，效果须由真实用户验证 |
| TalosBall、CodeFox | 状态表达与角色资产 | 视觉资产及运行时，不等同于独立智能体能力 |
| TALOS World | 世界、角色、关系及成果体验 | 长期项目；粒粒时空已归入第一阶段 |

## 已有关系的变化

Radar 的能力已归入 lili，保留其历史与参考价值。粒粒时空归入 World 第一阶段。AO 已纳入 World 规划，作为编码执行组件候选，目前尚未接入。Lens 与资料库各有用途，不互相替代。

## 共同基础

系统逐步统一资料含义、工作目标、重要决定、进度、授权和成果记录。各部分仍拥有自己的事实与数据；界面显示的摘要和统计需要能回到相应来源。

内部的结果管理、上下文精简、执行纪律、发行工程和升级参考管理，为这些用途提供基础。本仓库仅展示概念关系，不公开内部实现说明。
