# TALOS World

更新于 2026-09-10 · 长期愿景

**让人、智能体和真实工作的积累，共同进入持续存在的数字世界。**

## 可以想象的体验

你进入一个熟悉的空间，与记得过去交流的角色相遇。它们有各自的身份、关系和能力。你提出目标，在明确授权后，角色使用相关知识并寻找合适的协作者；你可以观察进展、作出决定，并查看最后的成果。

这些成果可以继续存在于世界中，也可以用于现实工作。角色与人的关系、已认可的经验和共同完成的事情，构成后续互动的背景。以上是目标体验，不是当前完整产品的操作说明。

## 世界与现实的联系

角色的能力由实际执行结果支撑。模型说完成、界面出现动画、任务真正完成与用户接受成果，是不同的事情。世界的表达需要与真实进度和来源保持一致。

长期探索让个人或组织保有自己的数据与模型选择，通过共同规则连接。接入、共享和协作在授权范围内发生；不用把所有原始资料集中到同一个地方。

## 当前起点与后续方向

粒粒时空提供已有 Web 演示基础，包含角色互动、记忆、协作过程和成果物体验。演示中的任务不能当作真实智能体能力。

后续逐阶段探索节点协作、真实模型与工具能力、UE5 空间，以及有依据的能力成长。服务交换与能力市场属于更远期方向，当前不作时间、收益或交易能力承诺。

AO 已纳入规划，作为可独立验证的编码执行组件候选，尚未接入 World。世界客户端、实际执行与各自的数据来源保持明确职责。
