# TALOS 宣言：让积累支持持续工作

TALOS 从人的资料、目标与真实工作出发，帮助人与智能体在清楚的边界内持续协作。人决定目标、选择工具和 AI 的参与范围，并检查成果是否满足用途。

## 从自己的资料出发

笔记、文档、经验和已有成果有各自的来源与归属。需要使用时，应能理解其背景和用途，并由用户选择提供给模型或工具的范围。

## 围绕需要的结果

工作需要明确目标、已确认的决定、尚缺的信息和下一步。进度不仅看步骤是否执行，还要看成果是否能够用于原定目的。

## 让协作可以继续

对话可以结束，工作可以延续。保留必要的背景、决定、进度和成果，让下一次协作能够从已有基础出发，并允许人纠正或放弃旧判断。

## 人保留决定权

事实、推断、建议和用户决定应当区分。在已授权的范围内推进常规工作；涉及关键方向和重要边界时，由人作出决定。

## 让成果与经验回到积累

报告、方案、流程和经验可以成为后续工作的材料。通过真实使用、可核对的证据和反馈，逐步修正方法，而不是把一次演示当作普遍效果。

## 在实际任务中学习

学习和引导围绕具体工作展开：组织资料、提供背景、检查结果，再形成适合自己的协作方式。

## 面向长期愿景

长期方向包括让人的积累支持具有身份、记忆、关系和能力的智能体，并探索与真实工作相连的 [TALOS World](world.md)。这是方向和愿景，不代表相关能力已经实现或通过验收。
