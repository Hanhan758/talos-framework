# TALOS 系统与应用

TALOS 围绕人的资料、目标、经验和成果组织工作。不同部分各自建设、验证和发布；下图说明用途关系，不代表所有接口已经打通。

```text
人的资料、目标和经验
        ↓
资料库与工作方法：组织、检索、积累和形成成果
        ↓
控制与协作：记录任务状态、决定和可核对的进度
        ↓
使用入口：按需要通过资料库插件、桌面等方式参与
        ↓
长期探索：独立 Agent OS 运行系统与 TALOS World
```

| 部分 | 负责什么 | 当前范围 |
|---|---|---|
| **Framework** | 提供公开理念、框架文稿和基础模板。 | v0.5 文稿已发布；历史版本按原发布内容保留。 |
| **超级大脑资料库框架包** | 探索让使用者从新建库或已有资料开始，组织资料并与智能体协作。 | 部分新建、接入、升级流程已有本机候选验证；真实用户完整使用仍待验证。 |
| **TALOS System 控制底座** | 组织项目事实、任务状态、规则和受控协作。 | 特定本机基线已有验收记录；面向不同 AI 的统一入口仍在接口设计阶段。 |
| **TALOS Plugin** | 在 Obsidian 中提供与资料库和工作流程有关的使用入口。 | 有独立源码和发布版本；当前本地候选及公开版本的范围应分别看待。 |
| **TALOS Deck** | 探索桌面总控与交互入口。 | 有本机安装版本；语音和主动汇报的所有者实测尚未完成。 |
| **TALOS Haven** | 探索以资料小镇的方式浏览与讲解资料。 | 有演示候选，五站语音整体体验仍待验收。 |
| **独立 Agent OS runtime** | 规划独立组织模型会话、资料分析和任务接续的运行系统。 | 已有设计基线，产品开发尚未开始。 |
| **TALOS World** | 探索人与持续存在的智能体共同参与的长期数字世界。 | 是长期愿景；现有演示和未来能力需分别核对。 |

用户选择模型、工具和 AI 参与范围。是否使用本地或外部服务、数据发送到哪里，取决于所选服务与实际配置。资料、模型输出和已确认决定需要区分；具体的隐私和权限行为按组件版本及配置说明。
