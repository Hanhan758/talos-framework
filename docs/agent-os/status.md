# TALOS 当前状态

核对日期：2026-10-30。这里概述各部分的当前阶段；发布版本、单项测试、本机使用和真实用户验收分别描述，不能互相替代。具体交付以对应组件的版本说明为准。

| 部分 | 当前情况 | 尚待完成 |
|---|---|---|
| **公开 Framework** | v0.5 框架文稿已发布，本仓库保留历史论文与基础模板。 | 文稿发布不代表完整软件已正式发布。 |
| **资料库框架包** | 本机候选通过启动器完成新建资料库、接入旧库和升级流程的验证。 | 新库在 Obsidian 中启用后的显示、使用者界面核对及真实新用户完整流程仍待验证。 |
| **控制底座** | v1 的特定本机基线有验收记录。 | 这项记录不代表所有后续版本或所有产品均已验收。 |
| **跨 AI 统一入口** | 统一读取状态和提交进度提议的接口处于合同设计阶段。 | 接口范围仍待确认，跨客户端完整流程尚未完成。 |
| **TALOS Plugin** | 插件有独立公开仓库；本地候选随资料库框架继续建设。 | 本地候选不等于公开发行版本；实际可获取版本以 [Plugin Releases](https://github.com/WAINAO-Haaper/talos-plugin/releases) 为准。 |
| **TALOS Deck** | 已有本机安装版本，用于探索桌面总控入口。 | 语音问答、页面联动和主动汇报的所有者实测尚未完成。 |
| **TALOS Haven** | 已有资料小镇的演示候选。 | 完整五站语音体验仍待所有者验收；不能据此认定已完成客户演示或正式发布。 |
| **独立 Agent OS runtime** | 本机个人运行系统已有设计基线。 | 产品开发尚未开始，不能将理念文档视为已完成的运行系统。 |
| **TALOS World** | 作为长期方向探索持续存在的数字世界及人与智能体协作。 | 各相关能力尚未全部贯通；愿景不等于现有产品承诺。 |

完整产品的正式发布仍需真实新用户验证，以及适用的权利、商业和法律批准。文档更新与某个组件的发布，不会自动改变其他部分的验证状态。
